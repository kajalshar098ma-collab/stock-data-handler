
# Stock Data Handler

A simple Python project to fetch, analyze, save, and visualize stock market data using Yahoo Finance.

---

## Features

- Fetch historical stock data
- Calculate moving averages
- Save stock data as CSV
- Plot stock charts
- Easy to customize

---

## Technologies Used

- Python
- yfinance
- pandas
- matplotlib

---

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/stock-data-handler.git
cd stock-data-handler

##Install dependencies:

pip install -r requirements.txt
Run the Project
python main.py
Example

Enter a stock ticker when prompted:

AAPL

The program will:

Download stock data
Calculate moving averages
Save CSV file in data/
Display stock chart
